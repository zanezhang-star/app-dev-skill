把解压后的 `app-dev` 文件夹安装到 Hermes 当前 profile 的 skills 目录。

执行要求：
1. 先定位当前生效的旧版 `app-dev/SKILL.md`。
2. 备份整个旧版 app-dev 文件夹，备份名带时间戳。
3. 对比旧版和新版，输出关键差异，不要自动合并旧规则。
4. 将新版完整文件夹安装到原 app-dev 所在目录。
5. 不允许顺便修改新版 SKILL.md。
6. 安装后开启新 session 或重置 skill 缓存。
7. 验证 app-dev 能被列出，并测试：
   - 小型文案修改应判定 Quick
   - 核心指标修改应判定 Strict
   - 自动自我改写 app-dev 应被禁止
8. 最后用中文报告：安装路径、备份路径、版本、验证结果、是否存在冲突。
